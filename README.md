♻️ Campus Circular
The official peer-to-peer resource exchange network for Thakur Shyamnarayan Engineering College (TSEC).

📖 About The Project
Campus Circular is a decentralized, trust-based web platform designed to foster a circular economy within the college campus. It empowers students, labs, and workshops to seamlessly share, borrow, and lend academic resources—such as expensive textbooks, microcontrollers, media gear, and workshop tools—eliminating waste and saving money.

Built with a focus on real-world campus deployment, the platform features a simulated smart-locker integration, a gamified sustainability leaderboard, and a dedicated admin oversight console.

✨ Key Features
🧠 Need-Based Smart Match: An offline, simulated AI search that maps natural language queries (e.g., "I need to shoot a reel") directly to relevant inventory bundles (e.g., Sony Camera Kit).

⚡ Live Campus Feed & Trending: A real-time activity ticker and dynamic trending tags that make the campus network feel alive and bustling.

📦 Smart Locker Integration: "My Exchanges" dashboard generates interactive Pickup PINs and QR codes for secure, automated physical handovers.

📊 Sustainability Leaderboard: Tracks total money saved and e-waste diverted, featuring a gamified leaderboard ranking departments (AI & DS vs. ECE vs. Mechanical) by their circularity score.

⚖️ Admin Penalty & Compliance Console: A restricted-access portal for Student Affairs to manage disputes, track overdue items, calculate automated fines, and adjust student trust ratings.

🛡️ Trust & Karma Economy: Verified TSEC-ID profiles that track successful on-time returns, community karma points, and dynamic 5-star trust tiers.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom grid layouts, smooth UI animations, and hover physics)

Logic & State Management: Vanilla JavaScript (ES6+ Modules)

Visual Effects: Three.js (Lightweight 3D particle background rendering)

Architecture: 100% Client-side and offline-capable (Zero latency, perfect for live hackathon demos)

🎯 Hackathon Objective
This project was built to solve the real-world problem of resource underutilization on campus. By connecting students who need gear with students who have gear, Campus Circular promotes sustainability, reduces financial burden, and builds a tighter-knit engineering community.
